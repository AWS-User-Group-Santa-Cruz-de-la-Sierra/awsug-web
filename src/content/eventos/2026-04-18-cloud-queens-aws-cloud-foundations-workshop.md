## Cloud Queens \| AWS Cloud Foundations Workshop

El **AWS User Group Santa Cruz** se suma a la iniciativa **Cloud Queens**, una experiencia de aprendizaje diseñada para dar los **primeros pasos en cloud computing con AWS**.
Este **workshop presencial** está pensado para que las personas participantes conozcan los **fundamentos de la nube**, exploren la plataforma oficial **AWS Skill Builder**, y descubran cómo iniciar su **ruta de aprendizaje en AWS** de forma accesible y práctica.

Durante el evento:

* Introduciremos los **conceptos básicos de cloud computing** y el ecosistema de AWS
* Exploraremos la **ruta de aprendizaje AWS Cloud Foundations**
* Aprenderás a utilizar **AWS Skill Builder**, la plataforma oficial de aprendizaje
* Presentaremos el **Cloud Queens Challenge**, donde podrás continuar tu formación junto a la comunidad

Como incentivo para quienes completen el challenge, **se sortearán vouchers para certificación AWS**.

Este evento se realiza en coordinación con **comunidades tecnológicas y Women Techmakers**, en el contexto de las actividades del **Día Internacional de la Mujer**, con el objetivo de **impulsar más talento en cloud computing y fortalecer el ecosistema tecnológico local**.

🚀 **Si quieres empezar tu camino en AWS, este es el lugar perfecto para comenzar.**
